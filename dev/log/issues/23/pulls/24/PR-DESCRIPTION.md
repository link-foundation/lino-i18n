Fixes #23.

The reported Rust release staged version files before rebasing a concurrently advanced main, then failed with a dirty-index error. The JavaScript release published an accepted version again while registry readback was still invisible, producing staged-version E409 errors. Releases now synchronize validated metadata while clean, serialize all writers, and require verified registry visibility after an accepted publication. Source drift, invalid refs, malformed fragments and failed Actions output writes fail explicitly.

The same review covers the whole codebase: complete PR change detection and workspace/member version guards; strict locked installs; zero-warning lint/helper compilation; dependency audits; secrets, workflow and documentation checks; guarded manual releases; complete terminal status gates; supported runners and pinned tools. Both documentation publishers assemble the complete JS/Rust site. Existing public APIs, supported package runtime engines, release modes and npm recovery are preserved. JS and Rust patch fragments prepare the next release.
